# 하루쑥쑥 학습 프로그램

초등 1학년부터 중등 3학년까지 수학·영어·국어·사회를 학년별 난이도로 학습하는 웹 기반 학습 프로그램입니다.

## 주요 기능

- **학생 모드**: 학년 선택 후 수학·영어·국어·사회 매회 무작위 10문제 풀이 및 자동 채점
- **영어 학습**: 듣기(TTS)·쓰기·말하기(음성인식) 복습과 시험
- **학부모 모드**: 최대 4명의 자녀 등록, 학년 관리, 학습 기록 조회
- **오답 복습**: 틀린 문제 모아서 복습
- **다국어 지원**: 한국어/영어 UI 전환

## 설치 및 실행 방법

### 1. 필요 조건

- Windows 10/11
- Python 3.12 이상 설치 권장 (https://python.org)
- pip를 이용한 의존성 설치

### 2. 처음 실행 전 의존성 설치

프로젝트 폭더에서 다음 명령을 실행하세요.

```powershell
py -m pip install -r requirements.txt
```

### 3. 웹 실행 (권장)

#### 바탕화면 바로가기 생성

`바탕화면_바로가기_만들기.bat`을 더블클릭하면 바탕화면에 "하루쑥쑥" 바로가기가 생성됩니다.

#### 실행

생성된 바탕화면 "하루쑥쑥" 바로가기를 더블클릭하면:
1. 서버가 백그라운드에서 시작됩니다.
2. 자동으로 브라우저가 열리면서 `http://127.0.0.1:5000`으로 접속됩니다.
3. 한 번 더 클릭하면 "이미 실행 중"이라고 인식하고 브라우저만 다시 엽니다.

또는 직접 아래 파일을 실행할 수 있습니다.

```bat
start_and_open.bat
```

### 4. 수동 실행

```powershell
cd C:\Users\Administrator\Documents\math-english-learning
py run.py
```

실행 후 브라우저에서 `http://127.0.0.1:5000`으로 접속하세요.

### 5. 서버 중지

`stop_server.bat`을 더블클릭하면 실행 중인 서버를 중지할 수 있습니다.

## 회원가입 안내

- **학생**: 학년을 선택해 바로 학습을 시작합니다.
- **학부모**: 가입 시 최대 4명의 자녀 이름과 학년을 등록할 수 있습니다. 이후 "학부모 홈"에서 자녀를 관리합니다.

## 참고 사항

- 학습 기록은 SQLite 데이터베이스(`instance/learning.db`)에 저장됩니다.
- 데이터를 초기화하려면 `instance/learning.db` 파일을 삭제한 뒤 프로그램을 다시 실행하세요.
- 영어 음성인식은 Chrome/Edge 브라우저에서 가장 잘 작동합니다.
- PyInstaller exe 빌드는 현재 환경에서 오류가 발생하므로 사용하지 않습니다. 웹 방식으로 실행해 주세요.

## 문제 해결

### 바로가기를 눌러도 아무것도 안 뜸

1. 작업 관리자에서 `python.exe`, `pythonw.exe`, `py.exe`, `pyw.exe`를 모두 종료합니다.
2. `start_and_open.bat`을 한 번 더 더블클릭합니다.
3. 그래도 안 되면 프로젝트 폭더에서 `server.log` 파일을 확인해 주세요.

### 서버가 중복 실행됨

`start_and_open.bat`에 중복 실행 방지가 포함되어 있습니다. 하지만 기존에 남아 있던 Python 프로세스가 있다면 `stop_server.bat`으로 완전히 종료한 뒤 다시 실행하세요.

### 127.0.0.1:5000 접속 안 됨

- `py -m pip install -r requirements.txt`가 완료되었는지 확인하세요.
- 방화벽이 5000번 포트를 차단하지 않는지 확인하세요.
- 다른 프로그램이 5000번 포트를 사용 중일 수 있습니다. 이 경우 `stop_server.bat`을 먼저 실행해 보세요.
